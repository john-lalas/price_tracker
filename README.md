# price_tracker
## Motivation
Many people wait for discounts before buying something.

Maybe it is:

- A laptop
- A phone
- A programming course
- A gaming product
- A software subscription

Instead of manually checking prices every day, create a price tracking system.

The workflow:

- User saves a product URL
- Your service checks the price regularly
- The system compares price changes
- A notification is sent when the price reaches your target

Example:

“The Mac Mini M4 price dropped by $100.”

You receive an email immediately.

This project teaches practical skills:

### Web scraping
Learning how websites expose information and how to extract useful data.

### Scheduling
Running tasks automatically:

```code
Every 6 hours:
    Check product prices
    Save results
    Compare changes
```

### Notifications
Connecting systems together:

- Email
- Telegram bot
- Push notifications
